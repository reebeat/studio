# reebeat studio

The collaborative editor for [reebeat](https://github.com/reebeat) stories. reebeat is the open compiler: a story goes in, a reveal.js Deck and a Video come out. Studio is where people (and their agents) edit a story and watch it play.

Status: the repository is being set up. Nothing here is usable yet.
