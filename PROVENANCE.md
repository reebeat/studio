## Generated, not copied

`apps/editor` was generated by `create-foldkit-app` 0.40.0 (`--name editor --rendering spa --example counter --package-manager bun`, run in a scratch directory; `foldkit` 0.169.0). Kept: `src/` (rewritten for the shell), `index.html` (title changed), `FOLDKIT.md` (Foldkit owns it, replaced whole on upgrade), `AGENTS.md` (its project notes written). Dropped: `.oxlintrc*.json`, `.oxfmtrc.json`, `vitest.config.ts`, `tsconfig.json`, `vite.config.ts`, `.mcp.json`, `README.md`, `package.json` (the root configuration and the files written for Vite+ replace them). Foldkit is MIT licensed; `foldkit` and `@foldkit/*` are installed from npm, not vendored.

## Spike code (branch `spike/collaboration-code`, spec 0002)

`spike/collab/` holds the throwaway measurement code behind [spec 0002](docs/specs/0002-collaboration-spike.md), with its raw output. It is not a workspace and is not held to the product's gates: `vite.config.ts` (`fmt.ignorePatterns`, `lint.ignorePatterns`), `knip.json` (`ignore`) and `.jscpd.json` (`ignore`) each gain the entry `spike/**`, so those three files differ from reebeat's `f7c3488`.

`spike/collab/ir/core-src/` is a **copy** of `packages/core/src` of [`reebeat/reebeat`](https://github.com/reebeat/reebeat) at commit `a01bb399da704e67c4e4e3511af17173d8e6ad4d` (branch `feat/0004-state-machines`, read from the committed tree with `git archive`; that commit is not on GitHub, which is why it is copied), unchanged. `spike/collab/ir/same-id.fountain` is `stories/same-id/story.fountain` of the same commit, unchanged (SHA-256 `6a71b9fa2f96837034b0cffd6c90023c4d374f2ad75e55a7151308f3f50b8e9e`). reebeat's licence file is still pending; the copy is for the spike's reproducibility and goes when reebeat publishes the commit.
